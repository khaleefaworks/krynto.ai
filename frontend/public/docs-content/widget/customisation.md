# Widget Customisation

All visual settings are managed from the dashboard — no code changes needed on your website.

## Accessing widget settings

**Settings → Websites → [your website] → Widget**

A live preview updates as you change settings.

## Appearance

| Setting | Description |
|---------|-------------|
| **Theme colour** | Hex colour used for the widget header, buttons, send button, and notification popup |
| **Position** | `Bottom Right` or `Bottom Left` |

## Header

| Setting | Description |
|---------|-------------|
| **Widget title** | Text shown in the widget header bar (e.g. "Chat with us") |
| **Subtitle** | Second line under the title (e.g. "We reply in minutes") |
| **Agent avatar** | Show the assigned agent's avatar in the header |

## Chat bubble

| Setting | Description |
|---------|-------------|
| **Bubble icon** | The icon shown in the floating chat bubble |
| **Bubble size** | Size of the floating bubble |

## Notification popup

The small popup that appears above the bubble when an agent sends a message and the widget is collapsed.

| Setting | Description |
|---------|-------------|
| **Show popup** | Enable or disable the popup entirely |
| **Popup message** | Text shown in the popup (can include visitor's name as `{{name}}`) |

## Colors

Fine-grained color overrides for individual elements if the theme colour isn't enough.

## Features

| Setting | Description |
|---------|-------------|
| **Conversation history** | Let returning visitors view and navigate their past conversations |
| **File attachments** | Allow visitors to upload images and files |
| **Emoji picker** | Show emoji button in the message input |
| **CSAT rating** | Show a satisfaction rating after conversation is resolved |

## Sounds

| Setting | Description |
|---------|-------------|
| **Sound (collapsed)** | Played when a new message arrives and the widget is minimised — fires together with the notification popup |
| **Sound (open)** | Played when a new message arrives and the widget is open |

Options: `notification.mp3`, `blackberry2.mp3`, or silent.

## Saving changes

Click **Save** after making changes. The widget on your website reflects the new settings immediately on the next page load (settings are fetched fresh from the backend each time the widget initialises).
