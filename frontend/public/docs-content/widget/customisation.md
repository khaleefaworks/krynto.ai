# Widget Customization

AI ChatAssist provides a suite of customization tools to align the chat experience with your brand's visual identity.

---

## Accessing Customization Tools

To modify your widget's appearance and behavior, navigate to **Settings > Websites > [Target Website] > Widget**.

---

## Visual Identity & Placement

Control the foundational look and feel of the widget to ensure it complements your site's design.

| Setting | Configuration Detail |
| :--- | :--- |
| **Theme Color** | Define the primary brand color for the widget header, action buttons, and visual prompts. |
| **Widget Position** | Position the chat bubble in either the **Bottom-Right** or **Bottom-Left** corner of the viewport. |

---

## Branding the Interface

The header is the primary point of contact for your visitors. Use it to establish trust and set response expectations.

| Setting | Purpose |
| :--- | :--- |
| **Widget Title** | The primary headline displayed in the header (e.g., "Customer Support"). |
| **Subtitle** | Secondary text used to communicate availability or status (e.g., "Replies in under 5 minutes"). |
| **Agent Identity** | Toggle whether the active agent's avatar is displayed during a conversation. |

---

## Proactive Engagement Tools

Capture visitor attention even when the widget is minimized using visual and audio prompts.

- **Notification Popups**: Enable a subtle text bubble that appears above the chat icon when a new message is delivered. These can be personalized using dynamic tags like `{{name}}`.
- **Chat Bubble Icons**: Select the primary icon that represents your support channel (e.g., Chat, Question, or Help).

---

## Interactive Feature Set

Enhance the conversation experience with advanced features that drive engagement and satisfaction.

| Feature | Description |
| :--- | :--- |
| **Conversation History** | Allows returning visitors to securely view and resume their previous interactions. |
| **Media Attachments** | Enables visitors to upload images or documents for troubleshooting and context. |
| **Emoji Support** | Provides an integrated emoji picker for more expressive visitor communication. |
| **CSAT Ratings** | Automatically prompts visitors for a satisfaction rating once a conversation is marked as resolved. |

---

## Audio Feedback Logic

Configure distinct audio cues to alert visitors of incoming messages based on their current interaction state.

- **Collapsed Sound**: Played when an incoming message arrives while the widget is minimized. This works in tandem with the notification popup.
- **Open Sound**: A subtle audio cue delivered when a message arrives while the visitor is actively viewing the chat window.

---

## Real-Time Deployment

Changes saved in the dashboard are pushed to the AI ChatAssist cloud immediately. The widget on your website will automatically reflect the updated configuration upon the next page initialization, ensuring your visitor experience is always up to date.

> **Accessibility First**: When selecting a **Theme Color**, ensure there is sufficient contrast between the background and the text to maintain readability for all users.
