# Visitors & Contacts

## Visitors

**Customers → Visitors** shows every visitor session that has been tracked on your websites.

### What is a visitor session?

Each time someone opens a page with your widget, a unique `session_id` is created in their browser's session storage. This maps to a visitor record.

### Visitor row information

| Column | Description |
|--------|-------------|
| **Visitor** | Anonymous ID or name (from offline form) + chat icon if they have an active conversation |
| **Website** | Which of your websites they visited |
| **Came from** | Referrer URL or "Direct" for direct visits |
| **Location** | Country/city derived from IP |
| **Device** | Browser and OS |
| **Last seen** | Time of last activity |

### Opening a conversation from the Visitors page

- If the visitor has an active (open) conversation with at least one real message, click the chat icon or **Open conversation** to jump straight to it in the Chats page.
- If the conversation only has bot/automation messages (no real visitor message yet), a warning modal appears — the conversation is not actionable yet.

### Visitor detail panel

Click any row to expand the visitor detail panel on the right. It shows:
- Browsing history (pages visited, with timestamps)
- Conversation history (all conversations for this visitor)
- Contact information if collected

## Contacts

**Customers → Contacts** lists visitors who have provided their name, email, or phone — either via the offline form or by the agent tagging them.

> The contacts page is a filtered view of visitors with enriched data — not a separate entity.
