# Conversations

The **Conversations** page is your primary workspace — this is where you engage visitors, resolve queries, and manage your team's inbox.

---

## The Inbox Layout

The dashboard is split into three areas:

- **Left panel** — Filter, search, and navigate conversations.
- **Center panel** — The active chat thread and message composer.
- **Right panel** — Visitor details, contact info, browsing history, private notes, and form submissions.

---

## Conversation List

Each item in the list shows at a glance:

| Element | Description |
| :--- | :--- |
| **Visitor avatar** | Colour-coded avatar; the assigned agent's avatar appears as a small badge overlay. |
| **Visitor name / ID** | The visitor's name if known, or an anonymous short ID. |
| **#short_id** | Compact conversation reference (e.g. `#a1b2c3d4e5f6`) shown in the list for quick lookup. |
| **Website badge** | Which website this conversation came from. |
| **Last message preview** | Truncated excerpt of the most recent message. |
| **Timestamp** | Relative time of the last interaction. |
| **Unread count** | Badge showing messages you haven't seen yet. |
| **Tags** | Up to 3 tag chips displayed inline; overflow shown as `+N`. |

### Filters

| Filter | Purpose |
| :--- | :--- |
| **All** | All open conversations across your assigned websites. |
| **Mine** | Conversations specifically assigned to you. |
| **Unassigned** | New queries waiting for an agent to claim. |
| **Resolved** | Searchable archive of completed conversations. |

---

## Visitor Details Panel (Right Sidebar)

Selecting a conversation opens the right sidebar with:

- **IP address and device info** — shown as compact icon rows (globe icon for IP, monitor icon for device/browser).
- **Contact info** — name, email, phone (click any field to edit inline).
- **Private notes** — visible only to agents; add notes with the `+` button.
- **Browsing history** — chronological list of pages the visitor viewed in this session.
- **Form submissions** — any data the visitor submitted via embedded forms.
- **CSAT rating** — the visitor's satisfaction rating once the conversation is resolved.

---

## Engaging with Visitors

### Joining a Chat

New conversations appear in the **Unassigned** filter. Click **Join** to claim the conversation. Once joined, you are the primary agent and the exclusive recipient of push notifications for that thread.

> If multiple agents try to join simultaneously, only one succeeds — preventing duplicate responses.

### Real-Time Interaction

- **Typing indicators** — see when the visitor is composing.
- **Instant delivery** — no refresh needed on either side.
- **Spectating** — other agents can observe the chat without joining; they see messages live but do not receive push notifications.

### Response Shortcuts

Use **Shortcuts** (canned responses) to reply to frequent questions instantly. Type `/` in the composer to search your shortcuts by keyword.

---

## Resolving & Closing

Click **Resolve** to close a conversation. This moves it to the archive and shows the visitor a "Conversation ended" state in the widget. Visitors can optionally leave a satisfaction rating.

---

## Tagging Conversations

Apply tags from the **Tag Selector** in the conversation detail panel to categorise inquiries (e.g. `Sales`, `Billing`, `Bug`). Tags feed into the Analytics → Tag Usage report and appear as chips in the conversation list.
