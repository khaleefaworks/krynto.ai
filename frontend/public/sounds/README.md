# Notification sounds

Put your dashboard notification sound files in this folder.

This project uses a fixed, no-settings structure:

1) New visitor (first message / new chat)
- File: `new-notification.mp3`
- URL: `/sounds/new-notification.mp3`

2) Subsequent visitor messages
- File: `notification.mp3`
- URL: `/sounds/notification.mp3`

Notes
- Prefer `.mp3` for best browser compatibility.
- If a file is missing, the app falls back to a synthesized beep.
