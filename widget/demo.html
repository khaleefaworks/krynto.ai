🤖 AI ChatAssist - Demo Page

⚠️ Important: Setup Required

Before the chat widget will work, you must:

  1. Complete onboarding at localhost:5173/login
  2. Create a website in Dashboard → Settings → Websites
  3. Note the website ID (shown in the URL or website list)
  4. Update the embed code below with your actual website ID

Current widget is configured for website ID: 1
If no website with ID=1 exists, the widget will not appear on this page.

This is a demo page showing the AI ChatAssist visitor chat widget in action. The chat bubble should appear in the bottom-right corner of the page only after proper setup.

Configuration: data-website-id="1"
data-ws-url="ws://localhost:8000"
data-api-url="http://localhost:8000"

How to Test:

  1. Ensure backend server is running: cd backend && ./start_server.sh
  2. Ensure database has a website with ID=1
  3. Click the chat bubble in the bottom-right corner
  4. Send a message to test AI responses
  5. Test agent handoff functionality

Features Implemented:

  • ✅ WebSocket connection to backend
  • ✅ Session persistence (localStorage)
  • ✅ Auto-reconnect on disconnect
  • ✅ Message display (visitor, AI, agent)
  • ✅ Real-time bidirectional messaging
  • ✅ Dynamic configuration fetch from backend
  • ✅ Customizable theme, position, and colors
  • ✅ Responsive design

Widget Configuration:

The widget automatically fetches its configuration from the backend API: GET /websites/{website_id}/widget-config

If the API is unavailable, it falls back to sensible defaults:

  • Theme: dark
  • Position: bottom-right
  • Primary Color: #000000
  • Welcome Message: "Hi! How can we help you today?"
